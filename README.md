## 🎯 Sobre o Projeto

CvSharp é uma aplicação web completa que permite aos usuários criar currículos profissionais e otimizados especificamente para sistemas ATS (Applicant Tracking Systems). Com uma interface intuitiva e moderna, o sistema guia o usuário através de múltiplas seções, fornecendo sugestões em tempo real e um score de compatibilidade ATS.

**Por que CvSharp?**
- ✅ Interface moderna e intuitiva
- ✅ Otimização automática para ATS
- ✅ Geração de PDF profissional
- ✅ Análise em tempo real
- ✅ Completamente responsivo
- ✅ 100% open source

## 🚀 Quick Start

<div align="center">

### ⚡ Comece em 5 Minutos!

</div>

### 📋 Pré-requisitos

```bash
✅ Node.js v18+        # JavaScript runtime
✅ .NET SDK 10+        # Framework .NET
✅ npm ou yarn         # Gerenciador de pacotes  
✅ Git                 # Controle de versão
```

### ⚡ 5 Passos Simples

#### `1️⃣ Clone o Repositório`

```bash
git clone https://github.com/seu-usuario/CvSharp.git
cd CvSharp
```

#### `2️⃣ Instale Dependências`

```bash
# Frontend
cd CvSharp.client
npm install

# Backend (em outro terminal)
cd ../CvSharp.Server
dotnet restore
```

#### `3️⃣ Configure HTTPS`

```bash
# Gere certificado de desenvolvimento
dotnet dev-certs https --trust
```

#### `4️⃣ Inicie Backend e Frontend`

```bash
# Terminal 1: Backend
cd CvSharp.Server
dotnet run

# Terminal 2: Frontend
cd CvSharp.client
npm run dev
```

#### `5️⃣ Abra no Navegador`

```
🎉 https://localhost:57830
```

## 🎯 O que é Otimização para ATS?

### 📌 Entendendo ATS

**ATS** = Applicant Tracking System (Sistema de Rastreamento de Candidatos)

```
Fluxo de Recrutamento Moderno:

1. Candidato envia CV
     ↓
2. Sistema ATS recebe e processa
     ↓
3. ATS escaneia o documento
     ↓
4. Se não compatível → REJEITADO ❌
     ↓
5. Se compatível → Humano revisa ✅
     ↓
6. Entrevista, oferecimento, contratação
```

### 🎯 Por Que Otimizar?

- 🤖 **75% dos CVs** são rejeitados automaticamente por sistemas ATS
- ⏱️ **Menos de 6 segundos** é o tempo médio de leitura
- 🔍 **Palavras-chave** são 10x mais importantes
- 📄 **Formatação** pode fazer você ser descartado

### 📊 Score ATS Explicado
│ 40-59:  Aceitável ⚠️                 │
│ 0-39:   Precisa Melhorar ❌          │
└──────────────────────────────────────┘
```

### 💡 Dicas Práticas para Melhorar Score ATS

#### ✅ Faça Isso

```
✓ Use títulos de seção padronizados
  Exemplo: "EXPERIÊNCIA PROFISSIONAL" (não "Minhas Histórias")

✓ Adicione 5+ habilidades técnicas específicas
  Exemplo: "React, TypeScript, .NET Core" (não "Programação")

✓ Inclua múltiplas experiências profissionais
  Mínimo 2-3 posições anteriores

✓ Use palavras-chave relevantes para a vaga
  Estude a job description e inclua termos

✓ Mantenha formatação simples e limpa
  Sem cores, imagens, ou elementos gráficos

✓ Use nomes reconhecidos de tecnologias
  "React" em vez de "Framework de frontend"
```

#### ❌ Evite Isso

```
✗ Cores, fontes complexas ou criativas
  Impede que ATS leia corretamente

✗ Tabelas, gráficos, infográficos
  Sistemas ATS não conseguem processar

✗ Imagens, logos, QR codes
  Podem ser ignorados ou causar erro

✗ Linhas horizontais ou separadores
  Podem quebrar o parsing do documento

✗ Cabeçalhos personalizados/criativos
  Use padrão: "EXPERIÊNCIA", "HABILIDADES", etc

✗ Jargão vago ou genérico
  "Team player" vs "Coordenei equipe de 5 pessoas"
```

## 🐛 Solução de Problemas & FAQ

### ❌ Erro: "Connection refused" / "Unable to connect"

**Sintoma:** Aplicação não consegue comunicar com o backend

```bash
# ✅ Solução 1: Verifique se backend está rodando
cd CvSharp.Server
dotnet run
# Deve exibir: "Application started. Press Ctrl+C to shut down."

# ✅ Solução 2: Verifique porta correta em vite.config.ts
# Procure por: proxy: { '^/api': { target: 'https://localhost:5001'...

# ✅ Solução 3: Verifique firewall
# Abra porta 5001 e 57830 no firewall
```

### ❌ Erro: "Port already in use" / "EADDRINUSE"

**Sintoma:** Porta 57830 ou 5001 já está em uso

```bash
# ✅ Windows: Encontre e encerre processo na porta
netstat -ano | findstr :57830
taskkill /PID <PID> /F

# ✅ Linux/Mac: Encontre e encerre processo
lsof -i :57830
kill -9 <PID>

# ✅ Ou altere porta em vite.config.ts:
// server: { port: 3000 }
```

### ❌ Erro: "Cannot find module"

**Sintoma:** Erro durante npm install ou dotnet restore

```bash
# ✅ Solução 1: Limpe cache e reinstale
npm cache clean --force
rm -rf node_modules package-lock.json
npm install

# ✅ Solução 2: Backend
rm -rf bin obj
dotnet clean
dotnet restore
dotnet build
```

### ❌ Erro: "Certificate error" / "CERT_UNTRUSTED"

**Sintoma:** Navegador exibe aviso de certificado

```bash
# ✅ Solução: Regenere certificado de desenvolvimento
# Windows
dotnet dev-certs https --clean
dotnet dev-certs https --trust

# Linux/Mac
dotnet dev-certs https --clean
dotnet dev-certs https --trust
# Confirme no diálogo de segurança
```

### ❌ Erro ao gerar PDF / "Access Denied"

**Sintoma:** Falha ao criar arquivo PDF, erro de permissão

```bash
# ✅ Solução: Verifique permissões da pasta
# Windows (já está ok por padrão)

# Linux/Mac
chmod -R 755 CvSharp.Server/wwwroot/cvs/
chmod -R 755 CvSharp.Server/wwwroot/

# Ou crie pasta se não existir
mkdir -p CvSharp.Server/wwwroot/cvs/
```

### ❌ Erro: "Response 500 - Internal Server Error"

**Sintoma:** Backend retorna erro 500

```bash
# ✅ Solução: Verifique logs
# 1. Abra console do backend (terminal rodando 'dotnet run')
# 2. Procure pela mensagem de erro
# 3. Tente usar [SETUP.md](SETUP.md) para resolver

# ❌ Comum: Falta de dados obrigatórios
# Certifique-se que CVData tem:
// - PersonalInfo.FullName (obrigatório)
// - PersonalInfo.Email (obrigatório)
```

### ❓ Como Verificar se Tudo Está Funcionando?

```bash
# ✅ Use o script de verificação
bash health-check.sh

# Ou verifique manualmente:

# 1. Frontend
curl https://localhost:57830
# Deve retornar HTML da aplicação

# 2. Backend
curl https://localhost:5001/api/health
# Deve retornar { "status": "ok" }

# 3. API de Geração
curl -X POST https://localhost:5001/api/cv/generate \
  -H "Content-Type: application/json" \
  -d '{"personalInfo":{"fullName":"Teste","email":"test@test.com"}}'
# Deve retornar { "success": true, "fileUrl": "..." }
```
